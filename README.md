# Cisco Live Melbourne Webex Admin API Lab — LABCOL-1529

Customer-facing materials for the Cisco Live Melbourne lab, **Automating User, License, and Hybrid Services Management with Webex Admin APIs**.

The published lab guide is available at [ciscolivemelbourne.github.io](https://ciscolivemelbourne.github.io/).

This repository includes the MkDocs source for the attendee guide and the take-home `admin-api` bundle: the Python exercise scripts, the Bruno and Postman collections, and sample user data. Lab credentials are issued separately for each event and must never be committed to this repository.

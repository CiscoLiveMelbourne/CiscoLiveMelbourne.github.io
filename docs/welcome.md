# <center>Welcome!</center>

This lab shows you how to manage users, licenses, roles, and Hybrid Services with the **Webex Admin APIs**.

You will use Bruno and VS Code side by side against the lab organization. You will not use your production organization.

!!! webex "What to do first"
    1. Open [Overview](overview.md) and enter the administrator email, password, and verified domain your proctor gives you.
    2. Open Bruno and VS Code on the lab desktop, then start [Lab 0](lab0_token.md).
